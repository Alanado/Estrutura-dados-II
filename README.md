# Estrutura de Dados II - Atividades Práticas 💻

Este repositório contém as resoluções das atividades práticas da disciplina de Estrutura de Dados II, abordando conceitos de alocação estática (Arrays, Matrizes e Structs em C) e alocação dinâmica (Listas Encadeadas e Filas em Python).

## 📁 Estrutura do Repositório

O repositório está dividido em duas partes principais, correspondentes às aulas ministradas:

### 1. Aula02_C - Arrays, Matrizes e Structs (C/C++)

Nesta seção, estão resolvidos os exercícios propostos focados em manipulação de memória contígua e tipos de dados estruturados.

### 2. Aula03_Python - Estruturas Dinâmicas (Python)

Contém a implementação de um **Sistema de Atendimento de Clínica**.

* **Conceitos aplicados:** Referências, Mutabilidade, Nós (Nodes) e Filas (Queues).

## 🚀 Como executar

**Para os arquivos em C:**
Recomenda-se utilizar um compilador como o `gcc`.

` ` `bash
cd Aula02_C
gcc ex10.c -o ex10
./ex10
` ` `

**Para o arquivo em Python:**
Requer Python 3.x instalado.

` ` `bash
cd Aula03_Python
python sistema_clinica.py
` ` `
